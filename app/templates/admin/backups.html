Como agendar

O sistema guarda os horários e a retenção. Para evitar execução duplicada no servidor web, agende o comando abaixo no Agendador de Tarefas do Windows.

docker compose exec web flask backup-create

Para emergencia pelo terminal:

docker compose exec web flask backup-list
docker compose exec web flask backup-restore --id ID --confirm RESTAURAR
Restaurar substitui os dados atuais pelo conteúdo do backup. Antes de restaurar pela tela ou terminal, o sistema tenta criar um backup de segurança automaticamente.
